 결과표에 나온 **클러스터링 평가 지표들에 대한 설**

---

### 📊 주요 평가지표 설명

- **Silhouette Score (실루엣 점수)**

  - 범위: -1 ~ 1
  - 값이 클수록 좋습니다.
  - 각 데이터 포인트가 자기 클러스터와 다른 클러스터 사이에서 얼마나 잘 분리되어 있는지를 평가합니다.
  - **1에 가까움** → 군집이 잘 분리됨
  - **0 근처** → 군집이 겹침
  - **음수** → 잘못된 군집화 (데이터가 다른 클러스터에 더 가까움)
- **Calinski-Harabasz Index (CH 지수)**

  - 값이 클수록 좋습니다.
  - 클러스터 간 분산 대비 클러스터 내 분산을 평가합니다.
  - 즉, **클러스터가 서로 잘 떨어져 있고 내부가 밀집되어 있을수록** 높은 값이 나옵니다.
  - 빠르게 계산 가능해서 대규모 데이터에 자주 사용됩니다.
- **Davies-Bouldin Index (DB 지수)**

  - 값이 낮을수록 좋습니다.
  - 각 클러스터 간 유사도를 평가하는 지표입니다.
  - 클러스터가 서로 **덜 겹치고 더 분리되어 있을수록** 낮은 값이 나옵니다.
  - 0에 가까울수록 이상적인 군집화입니다.
- **N_Clusters (클러스터 수)**

  - 알고리즘이 최종적으로 만든 클러스터 개수입니다.
  - 예: KMeans는 목표 클러스터 수를 지정하지만, DBSCAN/OPTICS는 데이터 특성에 따라 자동으로 결정합니다.
- **N_Noise (노이즈 포인트 수)**

  - DBSCAN, OPTICS 같은 밀도 기반 알고리즘에서 군집에 속하지 않는 데이터 포인트 수입니다.
  - 값이 크면 데이터 중 상당수가 군집화되지 못하고 노이즈로 분류된 것입니다.
- **Time (s)**

  - 해당 알고리즘을 실행하는 데 걸린 시간(초)입니다.
  - 데이터 크기와 알고리즘 복잡도에 따라 달라집니다.

---

### 🔍 결과 해석 팁

- **Affinity Propagation (ap)** → Silhouette 0.26으로 가장 높은 점수, 클러스터 수가 많음(17개).
- **KMeans, Spectral, Birch** → Silhouette이 0.1 근처로 낮음, 군집 분리도가 약함.
- **DBSCAN, MeanShift** → Silhouette 0, 클러스터가 1개만 생성되어 의미 있는 군집화가 되지 않음.
- **K-Modes** → 음수 점수(-0.10)로 군집화가 잘못된 경우.
- **OPTICS** → Silhouette 0.067, 노이즈가 많아 군집 품질이 낮음.

**요약:**
비지도 학습에서는 라벨이 없기 때문에 *클러스터 품질을 데이터 자체로 평가하는 지표*를 사용합니다. 지도 학습에서는 라벨이 있으므로 *예측 결과와 정답을 직접 비교하는 지표*를 씁니다.

### 🔍 핵심 포인트

- **비지도 지표**는 라벨이 없는 상황에서 군집의 품질을 상대적으로 평가합니다.
- **지도 지표**는 라벨이 있는 상황에서 예측 결과와 정답을 직접 비교합니다.
- 따라서 데이터에 라벨이 있느냐 없느냐가 지표 선택의 가장 큰 기준입니다.

비지도 지표는 라벨 없이 군집 품질을 평가하고, 지도 지표는 실제 라벨과 예측 결과를 비교한다는 차이가 있습니다.

### 📊 핵심 비교 요약

- **비지도 학습 지표**

  - **Silhouette Score**: 군집 내 응집도와 군집 간 분리도 평가 (높을수록 좋음)
  - **Calinski-Harabasz Index**: 군집 간 분산 대비 군집 내 분산 비율 (높을수록 좋음)
  - **Davies-Bouldin Index**: 군집 간 유사도 평균 (낮을수록 좋음)
  - **ARI / NMI**: 라벨이 있을 때 군집과 실제 라벨의 일치도 평가
- **지도 학습 지표**

  - **Accuracy**: 전체 예측 중 정답 비율
  - **Precision**: 양성 예측 중 실제 양성 비율
  - **Recall**: 실제 양성 중 올바르게 예측한 비율
  - **F1-score**: Precision과 Recall의 조화 평균
  - **ROC-AUC**: 양성/음성 분류 성능의 종합 지표

- **지도 지표**는 라벨이 있는 상황에서 예측 결과와 실제 라벨을 직접 비교합니다.
