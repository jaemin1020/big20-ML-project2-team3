# ✅ 1. high-price items만 subset하여 residual 분석

### 목적

* 고가 제품(예: 상위 10% 이상)에서 error가 더 크게 나타날 가능성 검증
* high-price 전용 모델 필요성 판단

### 코드 방향

```python
threshold = y_true.quantile(0.9)
high_idx = y_true > threshold

residual_high = abs_err[high_idx]

mean_err = residual_high.mean()
```

그리고 이전에 만든 `plot_residual_by_category`, `plot_residual_by_brand`에 **high_idx 필터만 적용**하면 재활용 가능 👍

# ✅ 2. subcategory별 RMSE ranking

### 목적

* 어떤 세부 카테고리에서 모델 에러가 특이적으로 큰가?
* 단순 평균 오차가 아니라 RMSE로 ranking (high-error 진짜 outlier 검출)

### 코드

```python
from sklearn.metrics import mean_squared_error

rmse_map = {}
for sub in analyzer.train['sub_cat'].unique():
    idx = analyzer.train['sub_cat'] == sub
    rmse_map[sub] = mean_squared_error(y_true[idx], y_pred[idx], squared=False)

rmse_series = pd.Series(rmse_map).sort_values(ascending=False)
```

# ✅ 3. 브랜드별 residual + 가격대 분석

### 핵심 아이디어

* 브랜드마다 가격대 분포가 다름 → 'high-price 브랜드가 residual이 큰 것인가?' 를 구분해야 함

### 해야 할 것:

브랜드별

* 평균 가격
* median 가격
* 평균 residual
* residual / price ratio

### 코드 핵심:

```python
df = pd.DataFrame({
  "brand": analyzer.train['brand_name'],
  "price": y_true,
  "err": abs_err
})

df_group = df.groupby("brand").agg({
    "price": "mean",
    "err": "mean"
})
df_group["err_ratio"] = df_group["err"] / df_group["price"]
```

➡ **오차 비율(err_ratio)** 누가 높은지 ranking 하면 됨

---

# ✅ 4. Error Hot-Spot Detection (Z-score 이상치 탐지)

### 목적

* 특정 그룹 또는 특정 개별 아이템이 “심각하게 이상한” 경우 탐지
* fraud / mislabel / fake / spam listing 후보

### 방법

Residual Z-score 계산

```python
from scipy.stats import zscore
z = zscore(abs_err)

outliers = z > 3  # Top 0.1% 정도
```

또는 그룹별로

```python
err_z_group = (df_group["err"] - df_group["err"].mean()) / df_group["err"].std()
hotspots = err_z_group[err_z_group > 2]
```

➡ subcategory, brand, 또는 item level에서 “hot spot” 찾기 가능

## 🔍 이 그래프가 말해주는 핵심 포인트

### 1) **대부분의 고가 상품은 오차가 작다**

* 박스(상자)가 거의 0 근처에 밀집해 있어
* 즉 **대부분의 판매 가격에 대한 예측은 꽤 정확하다**는 뜻

---

### 2) **하지만 극단적인 outlier가 존재한다**

* 위로 길게 뻗은 점들(100, 200, 300, … 1600!)
* 즉 일부 고가 제품에서 **어마어마한 예측 오차가 튀어나온다**

👉 이는 단순 noise가 아니라, **모델이 특정 고가 제품 특성을 제대로 반영하지 못하는 영역이 있다**는 증거

---

### 3) 이건 “분산이 크다”는 증거

* 고가 영역에서 오차의 **variance가 커진다**
* 즉 신뢰구간이 낮아짐
* 모델의 안정성이 떨어지는 부분 존재

---

## 📌 해석을 한 마디로 요약하면

> “평균적으로는 괜찮지만, 비정상적으로 높은 가격대 제품에서  **예측 실패 위험이 매우 높다** ”

---

## 🧠 왜 그럴까?

고가 제품은

* 희소성 (샘플 수 적음)
* 브랜드 수준 다양
* category가 다양
* feature sparsity
* extreme pricing (collector item 등)

따라서 일반적인 패턴으로 예측이 어려움

---

## 💡 실제 개선 아이디어

* high-price 구간 별도 모델링 (two-stage model)
* price range segmentation
* quantile regression 적용
* heavy-tail loss 적용 (Huber, quantile)
* brand-specific fine tuning

> 고가 제품군(가격 상위 10%)에 대해 별도로 절대오차를 분석한 결과, 평균적으로는 낮은 오차를 보이나, 일부 고가 제품에서 매우 큰 절대오차가 관측되었습니다(최대 >1600 수준). 이는 모델이 특정 고가격 제품 특성을 충분히 반영하지 못하고 있으며, 고가 영역에서 예측 안정성이 떨어지는 것을 의미합니다. 따라서 고가격 제품군에 대한 별도 모델링 또는 이상치에 강인한 모델/손실함수 적용이 필요합니다.

# 📊 Top Brand Error Ratio 분석

## 그래프가 의미하는 것

Brand 별 “Error Ratio(= 예측오차 / 실제가격)” 상위 20개를 순서대로 비교한 결과임.

즉 **가격 대비 상대적 오차가 큰 브랜드**를 보여준다.

* RMSE(절대오차)는 고가 상품에 불리하지만
* Error Ratio는 상대지표라서,
  → 저가/중가 상품에서도 상대적으로 예측이 어렵다는 브랜드를 찾을 수 있음

### 1) Free People, MAC, Xbox 등이 최상위

### 4) Brand-specific bias 존재 가능성

특정 브랜드가 지속적으로 높은 에러 비율을 가진다는 것은,

* 아이템 스펙 미반영
* 카테고리 granularity 부족
* 브랜드 내 가격 분산이 넓음
* text feature 부족 (예: “limited edition”, “collector’s item”)
