# Opinosis 데이터셋 클러스터링 분석 리포트 (PyCaret 결과 기반)

제시된 PyCaret 클러스터링 결과를 바탕으로 각 알고리즘의 성능을 분석하고 최적의 모델을 제안합니다. 이 분석은 Silhouette, Calinski-Harabasz, Davies-Bouldin과 같은 내부 유효성 지표를 기준으로 합니다.

---

## 1. 클러스터링 성능 지표 요약

### 1. 분석 및 주요 인사이트
### 2.1. 최적 모델: Affinity Propagation (AP)
제시된 지표들을 종합했을 때, ap (Affinity Propagation) 알고리즘이 가장 우수한 성능을 보였습니다.
Silhouette Score (0.2434): 가장 높은 점수를 기록했습니다. 이는 클러스터들이 서로 비교적 잘 분리되어 있고, 각 데이터 포인트가 자신의 클러스터에 합리적으로 속해 있음을 나타냅니다.
Davies-Bouldin Score (1.3826): 가장 낮은 점수를 기록했습니다. 이는 클러스터 내의 분산은 작고(조밀함), 클러스터 간의 거리는 멀다(잘 분리됨)는 것을 의미합니다.
N_Clusters (17개): 17개의 군집을 자동으로 식별했습니다. 이는 데이터 내에 다양한 하위 주제나 패턴이 존재함을 시사합니다.
### 2.2. 고려할 만한 대안: Agglomerative Clustering (Hclust)
hclust는 Calinski-Harabasz Score에서 3.1612로 가장 높은 점수를 받았습니다. 이 지표는 군집이 조밀하면서도 잘 분리되었음을 강력하게 나타냅니다.
AP보다는 Silhouette 점수가 낮지만, 7개의 클러스터로 AP보다 더 적은 수의 군집을 생성하므로, 만약 17개가 너무 많다고 판단될 경우 유용한 대안이 될 수 있습니다.
### 2.3. 성능 미달/실패 모델
meanshift, dbscan: N_Clusters가 1로 나타나 모든 데이터를 하나의 군집으로 묶었습니다. 이는 현재 매개변수 설정이 데이터의 밀도를 반영하지 못해 클러스터링에 실패했음을 의미합니다.
kmodes: 유일하게 음수의 Silhouette 점수를 기록했으며, 이는 알고리즘이 현재 데이터 형식(아마도 실수형 벡터)에 적합하지 않음을 나타냅니다.

## 결론 및 제안 사항
Affinity Propagation 모델을 사용하여 17개로 분류된 결과를 채택하는 것을 권장합니다.
후속 작업: 실제 이 17개 클러스터에 속한 리뷰 텍스트들을 검토하여 각 클러스터가 어떤 특정 주제(예: "긍정적 가격 평가", "부정적 배송 경험")를 나타내는지 **해석(Interpretation)**하는 과정이 필요합니다.
