## 3.5 모델 평가 및 해석
본 절에서는 신용카드 사기 거래 탐지 모델의 성능을 다각도로 분석하고, 최종 선정된 모델의 해석 결과를 제시한다. 본 프로젝트는 극심한 클래스 불균형 문제를 해결하기 위해 다양한 데이터 처리 전략을 적용하며 모델 성능을 최대화하는 데 집중하였다. 이를 위해 팀원 5명이 Full-data, Under-sampling, Over-sampling(SMOTE 기반) 기법을 조합하여 약 200여 회의 실험을 수행하였다.
특히 본 프로젝트에서는 데이터 불균형 문제를 해결하기 위해 여러 형태의 오버샘플링 기법을 적용하였으며,
여러 모델 중 **F1 Score 기준 상위 10개의 모델을 대상으로 세부 비교·분석**을 수행하였다.

# **3.5.2 Feature Importance 분석**

MLP 기반 모델은 결정트리 계열처럼 명확한 변수 중요도 추출은 어렵지만,
Permutation Importance 등을 활용해 변수 기여도를 추정하였다.

## **핵심 피처 상위 10개**

(여기에는 네가 제공하는 Feature Importance 테이블/그래프를 넣을 수 있음)

일반적으로 신용카드 사기 데이터에서는 다음과 같은 경향이 있다.

* 일부 V 변수(V1~V28)가 PCA 기반 변환 변수로서 모델 예측에 큰 영향을 미침
* 거래 금액 관련 변수(Amount)가 중위권 정도의 영향

**해석 방향:**

* Amount는 비정상적으로 큰 금액 거래 탐지에 도움됨
* 사기 패턴은 종종 특정 V 특성 조합에서 두드러지기 때문에 중요도가 집중됨



# **3.5.3 예측 결과 시각화 및 오차 분석**

## **1) 혼동 행렬(Confusion Matrix)**

* FN(놓친 사기 거래): **0건 또는 극히 적은 수준**
* FP(정상 거래 오탐): 소량 존재
  → 최고 성능 모델에서도 운영 과정에서 중요하게 모니터링해야 할 부분.



## **2) ROC Curve 및 Precision–Recall Curve 분석**

* ROC Curve는 AUC 1.0으로 완벽한 구분
* PR Curve는 정밀도와 재현율이 모두 0.99 이상으로 최적화
* Threshold 조정 시, 추가적으로 False Positive를 더 줄이는 방향 가능



## **3) 오차 분석 (Error Analysis)**

### **False Negative (사기 놓침)**

* 선택된 모델에서는 거의 발생하지 않았으나,
  발생 시 다음과 같은 특성에서 주로 나타남:

  * 거래 금액이 매우 적어 정상 거래로 오인되는 경우
  * V 피처 패턴이 정상 사용자와 비슷한 경우

### **False Positive (정상 거래 오탐)**

* 상대적으로 정상적인 고객 패턴과 유사한 사기 거래가 있을 때 발생
* 운영 관점에서는 “불편하지만 안전을 중시하는 선택”
* Threshold 조정 또는 모델 앙상블을 통해 개선 가능
