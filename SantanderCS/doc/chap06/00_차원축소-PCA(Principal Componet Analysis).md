# 6장 차원축소

## PCA(Principal Componet Analysis)

대표적인 차원 축소 기법으로 PCA는 여러 변수 간 에 존재하는 상관관계를 이용해 이를 대표하는 **주성분(Principal Component)**을 추출해 차원을 축소 하는 기법

### 공분산

$C=ΡΣΡ^T$

P는 nXn의 직교행렬이며, 
Σ는 nxn 정방행렬, 
$P^T$는 행렬 P의 전치 행렬입니다. 위 식은 고유벡터 행렬과 고 유값 행렬로 다음과 같이 대응됩니다.

![image-20251118112451956](C:\Users\july1\AppData\Roaming\Typora\typora-user-images\image-20251118112451956.png)

공분산 C는 고유벡터 직교 행렬 * 고유값 정방 행렬 * 고유벡터 직교(90도) 행렬의 전치 행렬로 분해됩니다. 
\( e_i \)는 $i$번째 고유벡터를, \( \lambda_i \)는 $i$번째 고유벡터의 크기를 의미합니다.
**\( e_1 \)는 가장 분산이 큰 방향을 가진 고유벡터이며, **
**$e_2$는 \( e_1 \)에 수직-작교(독립)이면서 다음으로 가장 분산이 큰 방향을 가진 고유벡터**입니다.
$e_i^t$ 는 다시 원래데로 돌리는 것

내적은 90도로 직교하는 것

PCA는 다음과 같은 스텝으로 수행됩니다. 

1. 입력 데이터 세트의 공분산 행렬을 생성합니다. 
2. 공분산 행렬의 고유벡터와 고유값을 계산합니다. 
3. 고유값이 가장 큰 순으로 K개(PCA 변환 차수만큼만큼 고유벡터를 추출합니다. 
4. 고유값이 가장 큰 순으로 추출된 고유벡터를 이용해 새롭게 입력 데이터를 변환합니다.

PCA는 많은 속성으로 구성된 원본 데이터를 그 핵심을 구성하는 데이터로 압축한 것입니다.

### 차원 축소 필요성

1. 차원의 저주 
   차원이 높아질수록(피쳐 개수가 ↑) 데이터가 존재하는 공간의 부피가 기하급수족으로 ↑
   ㄴ 데이터(vector, point,점)의 양이 그대로라면 희소(sparse) 해진다. 
   ㄴ 패턴을 못찾는 문제 발생하고 ML 성능이 ↓
2. 과적합 발생확률이 ↑ 올라감
3. 계산 비용이 ↑ 늘어남

그래서 차원를 축소하고, 데이터 시각화(목적: 데이터 파악하려고 EDA)가 편리해진다

## 차원 축소 주요 기법

1. PCA : 비지도 학습(DATA만 사용) 데이터의 분산을 가장 크게 보존하는 축(기저: 주성분)을 순서대로 찾는 방식
             정방행렬만 사용 가능
2. LDA(Linear Discriminant Analysis) : 지도학습(DATA, LABEL), PCA와 유사하고, 분류에 사용
3. t-SNE(t-distributed Stochastic Neighbor Embedding) : t분포 확률이웃분포 : 시각화에 주로 사용된다. $=>$ 군집화(clustering)에 사용됨, 비선형(곡선)기법
4. SVD(Singular Value Decomposition): PCA와 동일하나, 비정방행렬에도 적용가능
5. AutoEncoder: 신경망(Deep Learning), 생성형 AI의 원조격

압축 : 새로운 축을 찾는 것, 새로운 축에는 기존 데이터들의 정보가 들어 있고 그걸 압축한 거다, 이때 손실이 발생할 수 있다

---

**LDA, t-SNE, SVD, AutoEncoder는 모두 고차원 데이터를 저차원으로 축소하거나 구조를 파악하는 데 사용되는 기법입니다. 각각의 목적과 방식이 다르며, 데이터 분석과 머신러닝에서 중요한 역할을 합니다.**

------

### 📊 1. LDA (Linear Discriminant Analysis)

- **목적:** 분류(classification)를 잘하기 위한 차원 축소
- **방식:** 클래스 간 분산은 최대화하고, 클래스 내 분산은 최소화하는 방향으로 데이터를 투영
- **특징:**
  - 지도학습 기반 (레이블 필요)
  - 클래스 구분이 잘 되도록 축을 찾음
  - 주로 분류 문제에서 전처리로 사용됨
- **예시:** 얼굴 인식, 문서 분류 등에서 클래스 간 경계를 명확히 하기 위해 사용

------

### 🌐 2. t-SNE (t-distributed Stochastic Neighbor Embedding)

- **목적:** 고차원 데이터를 시각화하기 위한 비선형 차원 축소
- **방식:** 데이터 간 거리(유사도)를 보존하면서 2D 또는 3D로 투영
- **특징:**
  - 비지도학습 기반
  - 클러스터 구조를 시각적으로 잘 표현
  - 계산 비용이 높고, 대규모 데이터에는 느림
- **예시:** 텍스트 임베딩, 이미지 특징 시각화, 유전자 데이터 분석

------

### 🧮 3. SVD (Singular Value Decomposition)

- **목적:** 행렬을 분해하여 데이터 구조를 파악하거나 압축
- **방식:** 행렬 $A$를 $ U \Sigma V^T $ 로 분해
  - $ \Sigma $: 특이값 → 중요 정보의 크기
- **특징:**
  - 선형 차원 축소
  - 노이즈 제거, 데이터 압축, 추천 시스템에 활용
- **예시:** Netflix 추천 시스템, 이미지 압축, 문서 유사도 분석

------

### 🧠 4. AutoEncoder

- **목적:** 데이터 압축 및 재구성 (비선형 차원 축소)
- **방식:** 인공신경망을 이용해 입력을 압축(인코딩)하고 다시 복원(디코딩)
- **특징:**
  - 비지도학습 기반
  - 복잡한 비선형 구조도 학습 가능
  - 다양한 변형: Denoising AE, Variational AE 등
- **예시:** 이상 탐지, 이미지 생성, 특징 추출

------

### 📊 차원 축소 기법 비교 요약

| 기법                                                    | 지도/비지도 | 선형/비선형 | 주요 목적               | 활용 분야              |
| ------------------------------------------------------- | ----------- | ----------- | ----------------------- | ---------------------- |
| **LDA** (Linear Discriminant Analysis)                  | 지도        | 선형        | 분류 성능 향상          | 얼굴 인식, 문서 분류   |
| **t-SNE** (t-distributed Stochastic Neighbor Embedding) | 비지도      | 비선형      | 시각화, 클러스터 구조   | 텍스트, 이미지 분석    |
| **SVD** (Singular Value Decomposition)                  | 비지도      | 선형        | 압축, 구조 분석         | 추천 시스템, 문서 분석 |

| **PCA** (Principal Component Analysis)                  | 비지도      | 선형        | 분산 최대 방향으로 축소 | 데이터 압축, 시각화    |

------

### 🧠 5. PCA란?

- **목적:** 데이터의 분산을 가장 잘 설명하는 방향으로 축을 재구성해 차원을 축소
- **방식:** 공분산 행렬의 고유벡터를 이용해 주성분(principal components)을 찾음
- **특징:**
  - 선형 차원 축소
  - 노이즈 제거, 시각화, 전처리에 유용
  - 데이터의 구조를 보존하면서 단순화

------

각 기법은 데이터의 성격과 목적에 따라 선택됩니다. 예를 들어:

- **시각화**가 목적이라면 → t-SNE, PCA
- **분류 성능 향상**이 목적이라면 → LDA
- **압축 및 재구성**이 목적이라면 → SVD, AutoEncoder
