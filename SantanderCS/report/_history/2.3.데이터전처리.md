## 2.3 데이터 전처리

본 프로젝트에서는 고객 불만족 예측 모델의 성능을 향상시키기 위해 데이터 정제, 결측치 처리, 이상치 보정, 클래스 불균형 대응, 피처 엔지니어링, 다중공선성 제거, 스케일링 등 다양한 전처리 과정을 수행하였다. 각 단계는 단순한 기술적 처리에 그치지 않고, 모델의 일반화 성능 향상과 데이터 품질 확보라는 목적을 기반으로 설계되었다.

### 2.3.1 분석에 불필요한 피처 제거

- **ID**: 단순 식별자이므로 예측에 기여하지 않음
- **TARGET**: 레이블이므로 입력 변수에 포함될 경우 데이터 누수 발생

**Feature/Target 분리 함수**

```python
def split_features_target(train_df, target_col="TARGET"):
    X = train_df.drop(["ID", target_col], axis=1)
    y = train_df[target_col]
    return X, y
```

#### 2.3.2.2 Zero-value 비율 99% 이상 피처 제거

- 데이터셋에 0값이 매우 많음
- 실제 0과 결측치 대체 0이 혼재
- Zero 비율 ≥ 99% → 정보량 부족 → 제거
- 제거된 피처 수: **220개**
- 상세 목록: `remove_cols_0.99.txt`

**Zero-value 기반 피처 제거 함수**

```python
def remove_zero_columns2(train_df, test_df, threshold_rate=0.99, save_report=True):
    summary_data = []
    for col in train_df.columns:
        zero_count = (train_df[col] == 0).sum()
        zero_rate = zero_count / len(train_df)
        mode_freq = train_df[col].value_counts().iloc[0]
        mode_rate = mode_freq / len(train_df)

        summary_data.append({
            "ColumnName": col,
            "na_Sum": train_df[col].isna().sum(),
            "nUnique": train_df[col].nunique(),
            "mode": train_df[col].mode()[0],
            "modeFreq": mode_freq,
            "modeFreqRate": f"{mode_rate * 100:.2f}%",
            "zero_count": zero_count,
            "zero_count_rate": zero_rate
        })

    summary_df = pd.DataFrame(summary_data)
    remove_cols = summary_df[summary_df["zero_count_rate"] > threshold_rate]["ColumnName"].tolist()

    clean_train_df = train_df.drop(remove_cols, axis=1)
    clean_test_df = test_df.drop(remove_cols, axis=1)
    return clean_train_df, clean_test_df
```

### 2.3.6 다중공선성 제거

- 상관계수 0.95 이상 피처 다수
- 동일 정보 중복 제공 → 과적합 위험
- 상관계수 기반 제거 수행
- 제거된 피처 수: **53개**
- 최종 피처 수: **96개**

**상관계수 기반 피처 제거 코드**

```python
def drop_highly_correlated_features(df, threshold=0.95):
    corr_matrix = df.corr().abs()
    upper = corr_matrix.where(np.triu(np.ones(corr_matrix.shape), k=1).astype(bool))
    to_drop = [column for column in upper.columns if any(upper[column] > threshold)]
    return df.drop(columns=to_drop), to_drop
```



### 2.3.7 스케일링

- 트리 기반 모델 → 스케일링 영향 적음
- 로지스틱 회귀, SVM, KNN 등 거리 기반 모델 → 스케일 차이에 민감
- StandardScaler 적용
  - 모델 간 성능 비교 공정성 확보
  - 최적화 수렴 속도 개선

```python
def scale_data(X_train, X_test):
    scaler = StandardScaler()
    X_train_scaled = scaler.fit_transform(X_train)
    X_test_scaled = scaler.transform(X_test)
    return X_train_scaled, X_test_scaled, scaler
```
