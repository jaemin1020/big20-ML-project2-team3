### 📑 샘플링 기법별 특징과 속도 비교

| 기법 | 원리 | 장점 | 단점 | 속도 |
|------|------|------|------|------|
| **SMOTE** | 소수 클래스 주변에서 합성 샘플 생성 (k-NN 기반) | 데이터 다양성 증가, 과적합 완화 | 계산량 많음, 대규모 데이터에서 느림 | **느림 (수십만 건이면 수 분~수 시간)** |
| **Random Undersampling** | 다수 클래스 샘플 무작위 제거 | 빠름, 간단 | 정보 손실 큼, 데이터 편향 가능 | **매우 빠름** |
| **Random Oversampling** | 소수 클래스 샘플 단순 복제 | 구현 간단, 빠름 | 과적합 위험 | **중간 정도** |

### 🧩 레포트 작성 시 강조 포인트
- **Accuracy만 보면 착각**할 수 있으니 Precision/Recall/F1을 함께 제시해야 함.  
- **불균형 데이터 문제**를 해결하기 위해 샘플링 기법을 적용했음을 설명.  
- 각 기법의 **속도 차이와 장단점**을 비교해, 실제 대규모 데이터에서는 어떤 접근이 현실적인지 논의.  
- `class_weight='balanced'` 같은 모델 옵션도 대안으로 언급하면 좋음.

📑 샘플 문단 (레포트용)
데이터셋은 정상 클래스가 압도적으로 많은 불균형 구조를 가지고 있어 단순 정확도(Accuracy)만으로는 모델 성능을 올바르게 평가하기 어렵다. 실제로 Linear SVM 결과에서 정상 클래스(0)는 거의 완벽하게 분류되었지만, 이상 클래스(1)는 Recall은 높으나 Precision이 매우 낮아 False Positive가 다수 발생하였다. 이러한 문제를 해결하기 위해 다양한 샘플링 기법을 적용할 수 있다. Random Undersampling은 다수 클래스 데이터를 줄여 빠르게 학습할 수 있으나 정보 손실이 크다는 단점이 있으며, Random Oversampling은 소수 클래스 데이터를 단순 복제하여 균형을 맞추지만 과적합 위험이 존재한다. SMOTE는 소수 클래스 주변에서 새로운 합성 샘플을 생성하여 데이터 다양성을 확보할 수 있으나, k-NN 기반 연산으로 인해 대규모 데이터에서는 처리 시간이 길어질 수 있다. 따라서 불균형 데이터 문제를 다룰 때는 각 기법의 장단점과 데이터 규모를 고려하여 적절한 방법을 선택하는 것이 중요하다.
