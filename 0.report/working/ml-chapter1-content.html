1.1 개요

1.1.1 머신러닝의 기본 개념 및 목표

머신러닝(Machine Learning)은 명시적인 프로그래밍 없이 컴퓨터가 데이터로부터 학습하여 패턴을 발견하고 예측을 수행하는 인공지능의 한 분야입니다. 1959년 Arthur Samuel이 "명시적으로 프로그래밍하지 않고도 컴퓨터에게 학습 능력을 부여하는 연구 분야"라고 정의한 이래, 현대 산업의 핵심 기술로 자리잡았습니다.

💡 머신러닝의 3가지 주요 학습 방식

  • 지도 학습 (Supervised Learning): 정답(레이블)이 있는 데이터로 학습하여 예측 모델을 만드는 방식. 분류(Classification)와 회귀(Regression)가 대표적입니다.
  • 비지도 학습 (Unsupervised Learning): 정답 없이 데이터의 패턴이나 구조를 발견하는 방식. 군집화(Clustering), 차원 축소 등이 있습니다.
  • 강화 학습 (Reinforcement Learning): 환경과의 상호작용을 통해 보상을 최대화하는 방향으로 학습하는 방식입니다.

본 프로젝트에서는 지도 학습을 중심으로 4가지 실제 데이터셋을 분석합니다. 머신러닝의 궁극적 목표는 단순히 학습 데이터에 잘 맞는 모델이 아닌, 새로운 데이터(test data)에 대해서도 정확한 예측을 수행하는 일반화(Generalization) 능력을 갖춘 모델을 개발하는 것입니다.

1.1.2 정형 데이터 분류 문제 이해

정형 데이터(Structured Data)는 행과 열로 구성된 테이블 형태의 데이터로, CSV, Excel, 데이터베이스 등에 저장됩니다. 비정형 데이터(이미지, 텍스트, 음성)와 달리 명확한 구조를 가지며, 통계적 분석과 머신러닝에 직접 활용할 수 있습니다.

분류 문제(Classification)는 주어진 입력 데이터를 미리 정의된 범주(클래스) 중 하나로 예측하는 문제입니다:

1.1.3 모델 평가의 중요성

머신러닝 모델의 성능을 평가하는 것은 모델 개발만큼 중요합니다. 단순히 정확도(Accuracy)만 보는 것이 아니라, 문제의 특성에 맞는 적절한 평가 지표를 선택해야 합니다.

⚠️ 불균형 데이터에서 정확도의 함정

예: 신용카드 거래 10,000건 중 사기는 10건(0.1%)

→ 모든 거래를 "정상"으로 예측해도 정확도 99.9%!

→ 하지만 실제로는 사기를 하나도 탐지하지 못함

해결책: Precision, Recall, F1-Score, AUC 등 다양한 지표 활용

따라서 본 프로젝트에서는 각 데이터셋의 특성에 맞는 다양한 평가 지표를 사용하며, 특히 불균형 데이터셋에서는 Recall, F1-Score, AUC에 주목합니다.

1.2 분류 (Classification)

1.2.1 분류 개요

분류 문제의 정의

분류(Classification)는 입력 특성(features)을 바탕으로 데이터가 어떤 범주(category)에 속하는지 예측하는 지도 학습의 대표적인 문제입니다. 수학적으로는 입력 공간 X에서 이산적인 출력 공간 Y로의 함수 f: X → Y를 학습하는 과정입니다.

평가 지표

1) 정확도 (Accuracy)

전체 예측 중 올바르게 예측한 비율입니다. 가장 직관적이지만, 클래스 불균형 시 신뢰할 수 없습니다.

Accuracy = (TP + TN) / (TP + TN + FP + FN)

2) 정밀도 (Precision)

모델이 Positive로 예측한 것 중 실제 Positive의 비율입니다. "양성 예측의 신뢰도"를 나타냅니다.

Precision = TP / (TP + FP)

예시: 스팸 필터에서 정밀도가 높다 = 스팸으로 분류한 메일이 실제로 스팸일 확률이 높다

3) 재현율 (Recall, Sensitivity)

실제 Positive 중 모델이 Positive로 예측한 비율입니다. "실제 양성을 얼마나 찾아냈는가"를 나타냅니다.

Recall = TP / (TP + FN)

예시: 암 진단에서 재현율이 높다 = 실제 암 환자를 놓치지 않고 탐지

4) F1 Score

Precision과 Recall의 조화 평균입니다. 두 지표의 균형을 고려합니다.

F1 = 2 × (Precision × Recall) / (Precision + Recall)

📊 Precision vs Recall 트레이드오프

  • Precision 우선: 잘못된 양성 판정의 비용이 큰 경우 (스팸 필터, 추천 시스템)
  • Recall 우선: 놓치는 것(FN)의 비용이 큰 경우 (암 진단, 사기 탐지)
  • F1 Score: 둘 다 중요한 경우 (일반적인 상황)

혼동행렬 (Confusion Matrix)

예측 결과를 4가지 경우로 분류한 표입니다. 모든 분류 지표의 기초가 됩니다.

ROC 곡선과 AUC

ROC 곡선(Receiver Operating Characteristic Curve)은 분류 모델의 성능을 시각화하는 도구입니다. X축에 FPR(False Positive Rate), Y축에 TPR(True Positive Rate, Recall)을 놓고 임계값(threshold)을 변화시키며 그린 곡선입니다.

FPR = FP / (FP + TN)
TPR = TP / (TP + FN) = Recall

AUC(Area Under the Curve)는 ROC 곡선 아래 면적으로, 0.5~1.0 사이의 값을 가집니다:

  • AUC = 1.0: 완벽한 분류
  • AUC = 0.9~1.0: 매우 우수
  • AUC = 0.8~0.9: 우수
  • AUC = 0.7~0.8: 양호
  • AUC = 0.5: 동전 던지기 (무작위)

💡 AUC의 장점

  • 임계값에 독립적인 평가 가능
  • 클래스 불균형에 비교적 강건
  • 모델의 전반적인 성능을 하나의 수치로 표현

1.2.2 결정 트리 (Decision Tree)

결정 트리의 구조

결정 트리는 데이터를 규칙(rule) 기반으로 분할하여 트리 구조를 만드는 알고리즘입니다. 직관적이고 해석하기 쉬운 화이트박스 모델입니다.

  • 루트 노드 (Root Node): 전체 데이터셋을 포함하는 최상위 노드
  • 규칙 노드 (Decision Node): 특정 조건으로 데이터를 분할하는 중간 노드
  • 리프 노드 (Leaf Node): 최종 예측 결과를 나타내는 말단 노드

🌳 결정 트리 예시 (타이타닉 생존 예측)

성별이 남성인가?
├─ Yes → 사망 (정확도: 81%)
└─ No → 나이가 18세 이상인가?
    ├─ Yes → 1등실 승객인가?
    │    ├─ Yes → 생존
    │    └─ No → 사망
    └─ No → 생존 (정확도: 85%)

불순도 측정

결정 트리는 데이터를 분할할 때 불순도(Impurity)가 가장 많이 감소하는 기준을 선택합니다. 불순도는 한 노드 안에 서로 다른 클래스가 섞여있는 정도를 나타냅니다.

1) 지니 계수 (Gini Index)

Scikit-learn의 기본 설정입니다. 계산이 빠르고 효율적입니다.

Gini = 1 - Σ(p_i)²
(p_i: 클래스 i의 비율)

2) 엔트로피 (Entropy)

정보 이론에 기반한 불순도 측정 방법입니다.

Entropy = -Σ(p_i × log₂(p_i))

3) 정보 이득 (Information Gain)

분할 전후의 엔트로피 차이로, 정보 이득이 큰 특성을 선택합니다.

Information Gain = Entropy(부모) - 가중평균(Entropy(자식))

하이퍼파라미터

파라미터 설명 기본값
max_depth 트리의 최대 깊이. 깊을수록 과적합 위험 None (제한없음)
min_samples_split 노드를 분할하기 위한 최소 샘플 수 2
min_samples_leaf 리프 노드가 되기 위한 최소 샘플 수 1
max_features 분할 시 고려할 최대 특성 수 None (전체)

과적합 제어 방법

결정 트리는 과적합(Overfitting)에 매우 취약합니다. 제한 없이 성장하면 학습 데이터에만 완벽히 맞는 모델이 만들어집니다.

🔧 과적합 방지 전략

  • Pre-pruning (사전 가지치기): 트리 성장을 미리 제한
    • max_depth=5: 깊이 제한
    • min_samples_split=20: 분할 조건 강화
    • min_samples_leaf=10: 리프 크기 제한
  • Post-pruning (사후 가지치기): 트리를 키운 후 불필요한 가지 제거

Feature Importance

결정 트리는 각 특성이 예측에 얼마나 중요한지 자동으로 계산합니다. feature_importances_ 속성으로 확인할 수 있으며, 중요도가 높은 특성일수록 트리의 상단에 위치하고 불순도 감소에 크게 기여합니다.

1.2.3 앙상블 학습 (Ensemble Learning)

앙상블 학습의 개념

앙상블(Ensemble)은 "집단", "조합"을 의미합니다. 앙상블 학습은 여러 개의 약한 학습기(weak learner)를 결합하여 하나의 강한 학습기(strong learner)를 만드는 방법입니다.
